# Biblioteca de Tradinverso

Área privada. El contenido está cifrado con AES-GCM 256 y una clave derivada
por PBKDF2-SHA256 con 310.000 vueltas.

Sin la contraseña, `contenido.js`, `busqueda.js` y todo lo que hay en `d/` son
bytes sin sentido. No es una pantalla que se salte con F12: no hay nada que
saltar, los datos están cifrados.

Aquí no hay ningún documento en claro. Los originales viven fuera de este
repositorio.
